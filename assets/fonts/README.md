# Bundled fonts

- **Inter**: Google Fonts, `ofl/inter/Inter[opsz,wght].ttf`, downloaded 2026-11-08 from
  https://github.com/google/fonts/tree/main/ofl/inter . The bundled static instances were generated with fontTools
  4.63.0, optical size 14 and weights 400/600 (`instantiateVariableFont`, `updateFontNames=True`).
- **JetBrains Mono Regular**: downloaded 2026-11-08 from
  https://github.com/JetBrains/JetBrainsMono/blob/master/fonts/ttf/JetBrainsMono-Regular.ttf . Unmodified.

Both use the SIL Open Font License 1.1. Original licences are included separately, and `FONT-LICENSES.txt` accompanies
the Windows installation. Fonts are embedded in the executables and registered for their processes only.
