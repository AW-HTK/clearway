Several AI coding sessions on one PC each start a build, a test suite or a local model at the same moment, and the machine freezes. Clearway is a small queue that sits next to the clock: before a heavy task, a session asks for a slot, waits for its turn, runs, then releases. A guard refuses heavy commands started without a slot.

How it works

1 · ASK
The session requests a slot
request_clearance("cargo test", ram="3G", cpu=4)
2 · HOLD
Clearway waits for room
Measured RAM and CPU on Windows and inside WSL, minus what the active tickets still need, minus a safety margin.
3 · CLEARED
Run, then release
release(ticket=41, code=0)

Install

  1. Download clearway-setup.exe from the latest release.
  2. Run it: it finds WSL, Claude Code and Codex, and shows what it will install. No administrator rights.
  3. Restart your sessions. Verify, on the last page, checks each one.

The guard

$ cargo build --release Blocked by hook Clearway: `cargo build` is a heavy command. First ask for a slot with request_clearance, run the command once cleared, then call release.

Builds, test suites, type checks, renders, docker builds and local models count as heavy. Everything else runs freely. If Clearway does not answer within 2 seconds, the guard lets the command through: it never locks a session out.

Trust

Each release's SHA256SUMS is signed with the maintainer's Ed25519 key, and Clearway refuses an update whose signature does not match. Updates are offered, never installed by themselves.
